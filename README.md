# David Elijah Umaru — Portfolio

Personal portfolio site for David Elijah Umaru, Computer Engineering senior at Colorado State University. Static site — no build step, no dependencies.

## Files

- `index.html` — page structure
- `styles.css` — theme, layout, responsive rules
- `script.js` — all content (experience, projects, leadership, awards) plus filtering/interaction logic
- `assets/resumes/` — tailored resume PDFs (Software, Automotive, Embedded), linked from the Resume section

See `HOW_TO_EDIT.txt` for how to edit content and preview locally.

## Publish with GitHub Pages

1. Create a repo named exactly `<your-github-username>.github.io`
2. Push this folder's contents to it
3. In the repo's Settings → Pages, set the source to the `main` branch
4. Live in a few minutes at `https://<your-github-username>.github.io`
